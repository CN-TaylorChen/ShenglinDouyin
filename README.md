# ShenglinDouyin · 声临·抖音版

抖音评论区录音转 AI 音色。悬浮球、设置页、玻璃外观整套沿用 **声临·陌陌版**（ShenglinMomo）。

## 两条入口

- **悬浮球**：48pt，四态光晕（空闲灰白 / 录音红 / 合成蓝 / 就绪蓝常亮）。
  单击展开胶囊、长按进设置、拖动自动贴边并记忆位置。整套交互与陌陌版完全一致。
- **评论顶栏波形按钮**：在评论区里更顺手，两条入口打开的是同一个设置页。

## 设置页（4 组）

| 组 | 项 |
|---|---|
| 语音 | 录音转音色 · 合成引擎 · 音色 · 输入文字合成 · 情绪 · 语速 · 音量 |
| 本地 | 本地音频（收藏 / 导入 / 目录）· 语音包 |
| 发送 | 合成口令 · 短录音补全 · 合成后先试听 · 失败时放回输入框 |
| 其它 | 悬浮球图标 · API 凭证 · 运行日志 |

陌陌版的「聊天记录（防撤回 / 修改聊天）」「虚拟定位」两组在抖音无对应场景，已移除。

## 执行链路

```
点麦克风 → 录音（球转红）→ 录完落盘（球转蓝）
        → 识别文字 → 豆包 TTS 2.0 合成
        → 回填音频 + 时长写回消息体 → 发出后球回灰
```

任一步失败都不动原文件，原声照发。

## 与陌陌版的差异

| 陌陌版做法 | 抖音版做法 |
|---|---|
| 接管 `MDAudioStreamBus`，边录边喂 PCM | 录完直接改文件（`audioFilePath`） |
| 输出 AMR / Ogg Opus | 沿用抖音自己的容器，不转格式 |
| 输入框打 `#tts` 口令触发 | 点麦克风即可，无需口令 |

## 编译

```bash
make            # 产物 ShenglinDouyin.dylib
```

推送到 GitHub 后由 `.github/workflows/build.yml` 在 macOS runner 上编译并打包 deb。

注入：TrollTools 选择抖音（`com.ss.iphone.ugc.Aweme`），注入 dylib 后重启。
